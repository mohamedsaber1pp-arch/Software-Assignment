1. PROJECT OVERVIEW
-------------------
This project is a Personal Budget Management System designed to help users
track income, expenses, and manage financial goals.
It follows a Layered Architecture (Entities, Controls, and Boundaries)
as specified in the SDS document.

2. TOOLS & TECHNOLOGIES
-----------------------
- Programming Language: Java.
- Development Environment: IntelliJ IDEA.
- Documentation Tool: JavaDoc (Generated via Command Line Interface).
- Design Methodology: C4 Model & SOLID Principles.

3. FILES INCLUDED IN THIS SUBMISSION
------------------------------------
- /src: Java source code containing all packages (entities, controls, boundaries).
- /javadoc_output: The generated HTML documentation for all classes.
- SDS_Document.pdf: The Software Design Specification including UML diagrams.
- README.txt: This file explaining the project structure.

4. KEY FEATURES IMPLEMENTED
---------------------------
- User Authentication (Login/Logout).
- Transaction Management (Add Income/Expense).
- Budget Limit Monitoring and Notifications.
- Savings Goals Tracking.
- Automated Report Generation.

5. HOW TO RUN THE PROGRAM
-------------------------
1. Open the project folder in IntelliJ IDEA.
2. Ensure JDK 17 or higher is configured.
3. Locate the 'Main.java' file in the boundaries package.
4. Run the main method to start the console application.
